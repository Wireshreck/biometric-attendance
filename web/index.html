Help

Setup

  1. Run the backend: cd backend, configure .env from .env.example, then python -m uvicorn app.main:app. This page is served by the backend itself.
  2. Sign in with your admin credentials when prompted (browser dialog).
  3. Hardware: R307S red→VIN, black→GND, yellow→GPIO32, green→GPIO33; DS3231 SDA→GPIO25, SCL→GPIO26; buzzer→GPIO27. OLED/LEDs removed.
  4. BLE: click Connect BLE in Device and pick biometric-attendance-esp32 (Chrome/Edge).
  5. Adding employees requires one provisioned device. In backend/ run:
    python -m app.provision_device --name demo-terminal --location lab --sensor-capacity 1000
    Save the printed bearer token for the device; no restart needed.

Offline mode

The console keeps working when the server or network drops: check-ins are queued in this browser (IndexedDB, survives restarts) and sync automatically on reconnect. Replays are idempotent — no duplicates. Counts show pending / failed in the banner and Devices → Offline sync. Queued data is retained 30 days. If the queue is full, sync before recording more.

Demo walkthrough

PING → dashboard refresh → enroll a slot → search it → attendance appears live → full diagnostic → CSV export.

AI setup

Enter the key in the AI Assistant view (Gemini key card) — it is stored server-side only. Or set GEMINI_API_KEY in backend/.env and restart. Without it the assistant answers from local data and says so. The key never leaves the server.
