Help — science-fair demo

  
    
    
  1. Setup: power the ESP32 over USB, keep R307S wiring fixed (red VIN, black GND, yellow GPIO32, green GPIO33, blue/white open), DS3231 on GPIO25/26, buzzer on GPIO27.
    2. 
    
  2. Pairing: click Connect BLE, pick biometric-attendance-esp32. No OLED/LEDs — watch this page and listen for the buzzer.
    3. 
    
  3. Enrollment: enter a slot, click Enroll, place finger, remove when asked, place again. Never claim success unless the device reports enroll_success.
    4. 
    
  4. Troubleshooting: R307S FAIL + SKIPPED dependents means check sensor power/wiring; DS3231 FAIL means check I2C wiring/pull-ups; RTC invalid blocks attendance timestamps.
    5. 
    
  5. Demo flow: PING → DEVICE_INFO → DEVICE_STATUS → RTC_GET → FINGERPRINT_COUNT → ENROLL → SEARCH → ATTENDANCE_READ → FULL_DIAGNOSTIC.
    6.
