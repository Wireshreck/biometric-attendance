# Troubleshooting Matrix

This project is not yet a functioning attendance app. Follow diagnostics only for tooling/artifacts that exist. **Disconnect USB before rewiring; never guess module voltages or short live rails.** Hardware sequence: [bring-up plan](../hardware/test-plan.md).

| Symptom | Likely cause | Diagnostic | Safe response |
| --- | --- | --- | --- |
| ESP32 will not flash / no COM port | Charge-only cable, missing USB-UART driver, wrong port, board in wrong boot state | Device Manager, `pio device list`, try known data cable/USB port | Install the identified CP210x/CH34x driver from its vendor; select correct board/port; use BOOT only per board docs. Do not add capacitors blindly. |
| ESP32 boot loop/reset | Supply sag, wiring short, boot strap pin loaded, firmware fault | Disconnect peripherals; serial log; measure 5V/3V3 during boot | Return to bare-board boot; re-add one module at a time; keep strapping/flash pins unconnected. |
| PlatformIO command/build fails | PlatformIO absent, dependency download/cache/version issue | `pio --version`; `pio run -v` in firmware | Use pinned `platformio.ini`; inspect first compiler/download error; clear project `.pio` only if safe and rebuild. |
| AS608 not detected | Wrong connector/pinout, crossed UART, baud mismatch, supply/logic incompatibility | Read exact module labels/manual; verify common ground, TX/RX, measured UART levels and supply; run diagnostic firmware (not present yet) | Disconnect until voltage known; wire sensor TX→GPIO16/RX→GPIO17 only after safe levels; use level shifter if required. |
| Finger enrollment fails | Dirty/damaged prism, poor repeated placement, full/unsupported slot, sensor command issue | Clean per module guidance; inspect capacity/state; log sensor result codes without personal data | Repeat with consenting synthetic adult tester; do not mark student active until sensor confirms; do not assume 300 slots. |
| Recognition no-match/slow | Capture/placement, enrollment quality, module variation, threshold/config | Record controlled genuine/non-match attempts and time; inspect sensor result | Report measurements and failures honestly; do not lower threshold without false-accept testing. |
| I2C scan shows no device | SDA/SCL reversed, no power/ground, incorrect address, 5V pull-up | Test each module alone at 3V3; measure bus high; scan GPIO21/22 at 100kHz | Correct wiring/module power; identify pull-up voltage; do not connect a 5V bus to ESP32. |
| RTC is wrong/resets | Cell absent/depleted, unsafe/mismatched charge circuit, not initialized, timezone confusion | Verify exact RTC breakout/cell; read status; compare UTC offset/time | Never charge a primary CR2032; initialize via planned local setup; reject events when time invalid. |
| Buzzer/LED not working or GPIO heats | Polarity/resistor missing, bare buzzer overcurrent, module active-low | Disconnect; check schematic/module current and series resistor | Use LED series resistors and a transistor-driver buzzer module; GPIO23 is a logic input only. |
| Wi-Fi does not connect | 5GHz-only SSID, wrong locally configured credential, weak/hidden network | Check 2.4GHz band, signal, device log without printing password | Use isolated 2.4GHz WPA2 demo WLAN; configure ignored local file; rotate any exposed credential. |
| Backend will not start | Missing/invalid `.env`, wrong venv/dependencies, wrong module path, migration failure, or port conflict | From `backend/`, check Python/dependencies, required admin config, `app/main.py`, and `Get-NetTCPConnection -LocalPort 8000` | Configure unique synthetic-demo admin credentials, activate the backend venv, run `python test_env.py` and pytest, inspect the local error; do not delete the DB as first response. |
| Database locked / migration failure | Multiple writers, connection leak, busy timeout, schema mismatch | Inspect app logs/correlation ID; check WAL and migration version; back up first | Stop duplicate servers; use transaction helpers; run backup/integrity checks before repair; never delete DB as first response. |
| Dashboard cannot reach API | Dashboard is not implemented yet; later causes include wrong host/IP, firewall, origin/auth issue | Verify frontend files exist before troubleshooting; then test `/health` locally and inspect browser network tab | Current vertical slice has no dashboard. Once implemented, confirm bind/firewall on isolated network; do not expose/port-forward. |
| Duplicate outcome unexpected | Event UUID reused, time offset incorrect, 60s boundary interpretation | Compare event UUID, offset-normalized capture time, stored outcome | Same UUID must return prior outcome; a different event within 60s suppresses; later same-day scan can record. See API contract. |
| Python venv/permission issue | Wrong interpreter or execution policy | `python --version`; invoke `.venv\Scripts\python.exe` directly | Recreate only the ignored venv if needed; use Process-scope PowerShell policy bypass rather than machine-wide policy change. |
| Git commit refused | Identity mismatch or repository permission issue | `git config user.name`; `git config user.email`; `git status`; `git remote -v` | Confirm the configured identity is yours; verify branch permissions; never rewrite shared history to bypass a rejection. |

For any hardware fault, record exact module/board revision and measurements before changing pin assignments or BOM.
